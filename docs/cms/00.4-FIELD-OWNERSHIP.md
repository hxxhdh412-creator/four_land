# 00.4 — Field ownership và bảo vệ dữ liệu CMS

Trạng thái: Implemented for legacy compatibility

## Mục tiêu

Ngăn Sheet/Zalo ghi đè chỉnh sửa thủ công trong CMS mà không làm gián đoạn schema production hiện tại. Cơ chế tương thích được lưu trong `data_json.cms_override_fields`; migration sau này có thể chuyển sang column riêng.

## Phân loại

### Nguồn sở hữu

`property_id`, `send_id`, `account_id`, `group_id`, `group_name`, `sender_id`, `sender_name`, `received_at` và dữ liệu nguồn thô được cập nhật từ Zalo/Sheet.

### Có thể override từ CMS

```text
address, district, ward, street,
property_type, area_text, area_number, dimensions,
bedrooms, bathrooms, structure, legal,
price_text, price_number, commission,
phone, notes, raw_text, normalized_text
```

Khi admin sửa một field trong danh sách này, API thêm tên field vào `data_json.cms_override_fields`. Sync lần sau giữ giá trị production cho field đó.

### CMS sở hữu/protected metadata

- Legacy status `ready`, `featured`, `rented`, `archived`.
- `data_json.view_count`.
- `data_json.is_featured`, `data_json.is_rented`.
- `data_json.cms` và `data_json.cms_override_fields`.

### Dẫn xuất

`image_count` là số ảnh nhìn thấy và được tính lại từ ảnh sau khi áp dụng tombstone. Về lâu dài nên tính bằng transaction/job thay vì hai luồng cùng ghi.

## Quy tắc merge sync

1. Hồ sơ mới: dùng dữ liệu nguồn.
2. Hồ sơ đã tồn tại: làm mới field nguồn chưa bị override.
3. Field trong `cms_override_fields`: giữ giá trị production, kể cả `null`.
4. Legacy admin status: giữ production.
5. Metadata CMS/view count: merge lại sau khi đọc JSON nguồn.
6. Duplicate trong nguồn: bỏ qua loser; không hard-delete production.
7. Tombstone ảnh vẫn được bảo toàn theo `(property_id, position)`.

## Giới hạn hiện tại

- Cơ chế đang nằm trong JSON để không cần migration ngay; chưa có constraint database.
- Admin cũ tự đánh dấu override từ thời điểm code mới được triển khai; các chỉnh sửa trước đó chưa có danh sách field lịch sử.
- Chưa có UI bỏ khóa override hoặc hiển thị nguồn/CMS side-by-side.
- Chưa có audit actor vì vẫn dùng mã admin chung.
- `sync:sheet` vẫn bị chặn do chênh lệch dữ liệu; thay đổi này chưa phải giấy phép chạy ghi.

## Test bắt buộc

- Chỉ field whitelist được ghi override.
- Không mất view count/metadata CMS.
- Field override giữ giá trị production.
- Field không override nhận cập nhật nguồn.
- Legacy admin status không bị Sheet ghi đè.
- Duplicate không kích hoạt hard-delete production.
